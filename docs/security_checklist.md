# Security Checklist for Launch

- [ ] **HTTPS / TLS:** The FastAPI app must run behind a reverse proxy (e.g., Nginx, Traefik, or AWS ALB) with SSL termination. Do not expose Uvicorn directly to the public internet.
- [ ] **Secrets Management:** `SECRET_KEY` and `DATABASE_URL` must be injected via environment variables (e.g., AWS Parameter Store, Doppler, or GitHub Secrets), NOT hardcoded.
- [ ] **Strong Passwords:** Ensure `SECRET_KEY` in production is a highly entropic random string (e.g., generated via `openssl rand -hex 32`).
- [ ] **CORS Configuration:** Configure `CORSMiddleware` in `main.py` to only allow specific frontend domains instead of `*`.
- [ ] **Rate Limiting:** Add a rate-limiter (e.g., `slowapi`) to the `/api/v1/auth/login` endpoint to prevent brute-force attacks.
- [ ] **Database Network Security:** The PostgreSQL database should be placed in a private subnet and only accept connections from the FastAPI container IP.
- [ ] **Encrypted Backups:** Database dumps generated by `pg_dump` must be encrypted before being pushed to offsite storage (e.g., AWS S3).
- [ ] **Dependency Scanning:** Run `pip-audit` or `safety` periodically to check for known vulnerabilities in Python packages.
